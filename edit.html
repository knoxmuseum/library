Adding to the Catalog

  1. To add a volume to the library, determine the library of congress call number and create a label
  2. To add the volume to the catalog, visit the library's github repository using the link below and sign in
    • Github login page
    • Username: knoxmuseum
    • Password: knoxknox76
  3. Go to the library repository, listed as "knoxmuseum/library"
  4. Click on the file that corresponds to the call number
    • Ex. So You Want a Good Museum by Carl E. Guthe has call number AM 1 .A533 no. 1, so it belongs in the classA.html file
    • Note: if you are shelving a film, magazine, or anything too large to stand on a shelf, it should be listed within the "multi.html" file
  5. Type the title, author, and call number in the proper place, following the steps in the formatting guide
    • Ex. So You Want a Good Museum has the earliest call number, so it belongs at the beginning of the list
  6. When you're done, click the green "commit changes..." button at the top right of the screen, then again at the bottom of the popup box. Changes may take 10 to 15 minutes to be visible on the website.

Formatting Guide

  1. The title should be listed first, followed by the author and the call number, which should be enclosed within parentheses
      2. Title, author (call number)
  2. Each entry should be wrapped in a <p> tag
    • <p>Title, author (call number)</p>
  3. The title should be wrapped in an <i> tag
    • <i>Title</i>, author (call number)
